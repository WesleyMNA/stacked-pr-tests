# stacked-pr-tests

A small Python project scaffold with a sample `src/main.py` entry point.

## Requirements

- Python 3.14 or newer

The project currently has no third-party dependencies.

## Run

From the project root, run:

```bash
python src/main.py
```

The sample prints a greeting to `PyCharm`.

## Project structure

```text
src/
  __init__.py
  main.py
pyproject.toml
```

Project metadata and the supported Python version are defined in `pyproject.toml`.
